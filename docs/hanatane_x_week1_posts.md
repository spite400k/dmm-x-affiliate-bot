# @hanatane_app 投稿下書き（7日分）

そのままコピペして使える。投稿後は必ずスレッドで1通自己返信すること。

---

## Day1（月）即使用ネタ

**親**
```
雑談で沈黙したら、まずこれ👇

「最近、無駄に頑張っちゃったことある？」

答えが来たら「それ何分くらい？」で伸ばせる。
短く聞いて、10秒待つ。

#雑談配信
```

**スレッド**
```
応用:
・無駄に頑張った→次は「逆にサボれてよかったこと」
・コメントゼロなら自分のエピソードを先に出す
```

---

## Day2（火）あるある

**親**
```
雑談あるある、番号でリプしてほしい

1. 話題リスト、開始5分で空になる
2. コメント待ちの沈黙がいちばん長い
3. 「えー」「あのー」が増える
4. スマホ見下ろした瞬間にバレる
```

**スレッド**
```
4がいちばん痛い人、保険ネタを手元に置いておくだけで呼吸が変わることが多いです。
```

## Day3（水）デモ短尺

**親（動画添付）**
```
詰まったときの「次のお題」出し方（20秒）

読むためじゃなく、リスナーに振るためのカード。
```

**スレッド**
```
使い方のコツ:
お題を出したら、すぐ自分で答えきらない。
「みんななら？」を残す。
```

## Day4（木）即使用ネタ

**親**
```
今日の雑談お題（コピペ可）

「初めて買った推しグッズ、覚えてる？」

掘り方:
・どこで買ったか
・届いた日の気持ち
・今も持ってるか
```

**スレッド**
```
グッズ話はコメントが来やすい。
来たら「そのシリーズ好きな人いる？」で横に広げる。
```

## Day5（金）開発メモ

**親**
```
小さな改善メモ

沈黙対策の投稿、同じ言い回しが続いてたので止めます。
これからは
・すぐ使えるお題
・あるある
・短いデモ
をローテします。

見やすい方がいいので、気になる形式があれば教えてください。
```

**スレッド**
```
フィードバック歓迎です。
「このお題シリーズほしい」などあればリプでどうぞ。
```

---

## Day6（土）質問投稿

**親**
```
雑談配信者に聞きたい。

話題が尽きたとき、いちばん効くのはどれ？

A 二択を投げる
B 自分の失敗談を出す
C マシュマロ／質問箱
D お題ガチャ・ネタカード

リプで A〜D もらえると助かります。
```

**スレッド**
```
自分は D を保険にしつつ、A でコメントの入口を作る派です。
```

## Day7（日）あるある弱め or 休み

休むならリプ活動のみ。出すなら短く:

**親**
```
沈黙そのものより、
「次の一文がない」のが怖い。

一文あるだけで、配信の肩の力が抜けることがある。
```

**スレッド**
```
紙メモでもアプリでもいい。
形より「次がある」安心感の話です。
```

## 毎日のリプ活動（投稿とは別）

検索例:
- `沈黙 雑談`
- `話題 尽きた`
- `雑談 詰ま`
- `コメント来ない 配信`
