# @hanatane_app 投稿下書き（7日分・実測反映版）

公開表示回数の相対結果（地震126 / 時事ネタカード60 / 紹介動画22 / 沈黙対策2〜7）を踏まえ、**時事ネタカードを主軸**にした初週分。

投稿後は必ずスレッドで1通自己返信すること。
ネタの固有名詞は、投稿当日の Discover「VTuberニュース」に差し替える。

---

## Day1（月）時事ネタカード

**親**
```
【今日のネタ】HoloCozy、誰の部屋にする？

投げかけ:
「デスクトップ常駐させるなら、どのメンバーの部屋？」

自分の答えを先に言ってから振ると返しやすい。
```

**スレッド**
```
深掘りヒント:
・部屋に置くもの
・作業中に流したい曲
・「来客」に誰を呼ぶか
```

---

## Day2（火）時事ネタカード

**親**
```
【今日のネタ】新曲、どこで初聴きする？

投げかけ:
「配信中？ アーカイブ？ 通勤中？」

A/B/Cで振るとコメントのハードルが下がる。
```

**スレッド**
```
答えが来たら「なんでそこ？」で3分持つ。
固有名詞（事務所・楽曲名）がある日は、タイトルに必ず入れる。
```

## Day3（水）デモ短尺

**親（動画添付）**
```
詰まったときの「次のお題」出し方（20秒）

読むためじゃなく、リスナーに振るためのカード。
```

**スレッド**
```
使い方のコツ:
お題を出したら、すぐ自分で答えきらない。
「みんななら？」を残す。
```

## Day4（木）時事ネタカード

**親**
```
【今日のネタ】{当日のVTuberニュースを15字で}

投げかけ:
「{リスナーに振れる一文}」

深掘り: 自分ならどう答えるか、先に一言だけ。
```

**スレッド**
```
背景は1行で十分。
長いニュースコピペはスキップされやすいので、今日は投げかけ優先。
```

## Day5（金）沈黙Tips（旧・沈黙対策の置き換え）

**親**
```
コメントを振ったあと、すぐ自分で埋めない。

10秒空けるだけで、返りが来る確率が上がることが多い。
```

**スレッド**
```
保険ネタは2個で足りる、という話も今度書く。
同文の「沈黙対策 #n」連投は一旦やめています。
```
