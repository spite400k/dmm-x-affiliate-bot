# @hanatane_app X投稿 改善案

Grok診断（フォロワー28・IMP 5〜100・同文連投・エンゲージほぼゼロ）を踏まえた、**今すぐ実行できる**改善プラン。

現状フェーズは「拡散」ではなく **認知の種まき**。ゴールは「おすすめに載る」ではなく、**VTuber・雑談配信者のタイムラインに顔を出すこと**。

---

## 1. 診断の要約（優先度順）

| 優先度 | 問題 | 影響 |
|--------|------|------|
| P0 | 【沈黙対策 #n】同文連投 | スパム寄り判定・新鮮味ゼロ |
| P0 | 初速エンゲージがほぼゼロ | おすすめ配信に乗らない |
| P1 | コミュニティ接点が薄い | 外部流入ゼロ |
| P1 | 投稿フォーマットが固定 | スクロールでスキップされる |
| P2 | 固定ポスト・デモ動画が弱い | プロフ来訪者が離脱 |

**やめること（即日）**

- 同じ「沈黙対策」定型文の連番連投
- 「ネタカード画像＋同じ説明文」だけの日課
- ハッシュタグの羅列だけ／反応ゼロの独り言投稿

**やること（今週から）**

- 投稿は「実測で表示が伸びた型」を主軸にする（§3）
- 配信者投稿へのリプを「投稿」より優先
- 投稿直後にスレッド自己返信で初速を付ける

---

## 2. 運用の基本方針（フォロワー〜100人まで）

1. **売り込み比率を下げる**  
   1日の目安：時事ネタカード 50% / 人間味・共感 25% / デモ・訴求 15% / その他 10%
2. **「使える」投稿を増やす**  
   特に **今日のVTuberニュースに紐づく投げかけ**（実測で相対的に強い）
3. **反応が取りやすい形にする**  
   二択・質問・「あるある番号をリプして」など、リプのハードルを下げる
4. **時間帯**  
   目安は **21:00〜24:00**（雑談枠が動きやすい帯）。昼はリプ活動、夜は本投稿
5. **ハッシュタグ**  
   1投稿あたり **0〜2個**（`#雑談配信` `#VTuber` `#Vライバー` から状況で1つ）。毎回全部付けない

## 3. 投稿パターン（実測ビューに基づく再設計）

### 3.1 取得できた公開表示回数（直近・ログイン壁のため全月は未取得）

公開タイムラインから取れた **views（表示）**。いいね等の反応はいずれも0。アナリティクスの「インプレ」と同値ではないが、相対比較の代理指標として使用。

| 表示 | 日時(UTC) | 型 | 内容の要点 |
|------|-----------|----|------------|
| **126** | 8/22 | 人間味・時事 | 関東地震へのお見舞い（プロダクト無関係） |
| **60** | 8/23 | 時事ネタカード | ハコネクト3期生新曲＋配信での切り出し／投げかけ |
| **22** | 8/23 | アプリ紹介動画 | 固定のプロモ動画 |
| **7** | 8/22 | 沈黙対策 #21 | 同文テンプレ＋URL |
| **2** | 8/23 | 沈黙対策 #22 | #21と同文の連番 |

※ 過去1ヶ月の全投稿インプレはXログイン壁で取得不可。上位一覧のスクショ／CSVがあれば、この節を差し替え可能。

### 3.2 読み取れること

1. **同文「沈黙対策」はほぼ死んでいる**（2〜7）。連番を足しても伸びない。
2. **時事×使える投げかけのネタカードは、沈黙対策の約8〜30倍**（60 vs 2〜7）。プロダクト本線として最もコスパが良い。
3. **紹介動画はテンプレ文よりマシ**（22）だが、時事ネタカードには負ける。
4. **人間味のあるタイムリー投稿が最大**（126）。売り込みゼロでもリーチが出る。頻度は抑えて「顔が見える」用途に使う。

### 3.3 新しい主軸（優先度順）

同じ柱を連続させない。ローテは §6。

#### A. 時事連動ネタカード（最優先・週4〜5）

実測2位・プロダクトと一致。**長文のニュース背景は削る**。必要なのは次の3行だけ。

```
【今日のネタ】{話題を15字以内}

投げかけ:
「{リスナーに振れる一文}」

深掘りヒント: {自分の体験で続ける一言}
```

- ネタ元: ハナタネ Discover の「VTuberニュース」「話題ネタ」から当日分
- 事務所名・楽曲名など **固有名詞を入れる**（ハコネクト投稿が伸びた要因の一つ）
- アプリ名は本文に入れない。必要ならスレッド2通目

#### B. 人間味・タイムリー短文（週0〜2・無理に作らない）

実測1位。地震・天候・配信文化の「いま」など。**売り込み禁止**。アカウントが人に見えるための枠。

#### C. 短尺デモ動画（週1〜2）

実測3位クラスを狙う。15〜30秒で「お題が出る」一手だけ。長い機能説明は不要。

#### D. 沈黙Tips（沈黙対策の置き換え・週0〜1）

同文連番は廃止。出すなら **毎回違う切り口の1 Tips**（例: 「コメント待ちは10秒」「保険ネタは2個で足りる」）。連番ハッシュ不要。

#### E. コミュニティリプ（毎日・投稿枠外）

投稿パターンではないが、伸びの本体。§7・§9参照。

### 3.4 やめる／減らす（データ根拠）

| やめる | 理由 |
|--------|------|
| 【沈黙対策 #n】同文連投 | 表示 2〜7。最低水準 |
| ニュース全文コピペ型の長文カード | ハコネクト投稿も長い背景はスキップされやすい。投げかけが本体 |
| 「パターンを均等に5種」思考 | 均等分散より、**伸びたAを厚く**する |

### 3.5 データ不足で「まだ主軸にしない」

ユーザーの声・改善報告・あるある漫画は仮説としては有効だが、今回の公開ビューでは未検証。週1お試しまで。

## 4. すぐ使える投稿文案

### A. 時事連動ネタカード（主軸）

伸びたハコネクト投稿の型を **短くしたもの**。ニュース全文は不要。

**A-1（テンプレ）**
```
【今日のネタ】{固有名詞入りの話題}

投げかけ:
「{リスナーに振れる一文}」

深掘り: 自分ならどう答えるか、先に一言だけ持っておく。
```

**A-2（例・ゲームニュース）**
```
【今日のネタ】HoloCozy、部屋どう作る？

投げかけ:
「デスクトップに常駐させるなら、誰の部屋にする？」

深掘り: 自分の答えを先に言ってから振る。
```

**A-3（例・音楽／所属）**
```
【今日のネタ】新曲、どこで聴く？

投げかけ:
「初聴きは配信中？ アーカイブ？ 通勤中？」

A/Bで振るとコメントが返りやすい。
```

**スレッド2通目（任意）**
```
背景を1行だけ:
{ニュースの核を40字以内}

お題ストック用: プロフのリンク
```

### B. 人間味・タイムリー

**B-1**
```
今日の夜枠、暑さ負けしそうな人いる？
水分と休憩、ちゃんと取ってね。
```

（地震・災害級は事実確認後に短く安否気遣いのみ。話題化・ネタ化しない）

### C. 画面デモ用キャプション

**C-1**
```
詰まったとき用。お題を出すだけの20秒。

読むためじゃなく、リスナーに振るためのカード。
```

### D. 沈黙Tips（旧・沈黙対策の置き換え）

**D-1**
```
コメントを振ったあと、すぐ自分で埋めない。

10秒空けるだけで、返りが来る確率が上がることが多い。
```

**D-2**
```
保険ネタは5個いらない。

「二択」と「自分の失敗談」の2個あるだけで、肩の力が抜ける。
```

### E. リプ用テンプレ（他アカウントへ）

売り込み禁止。まず共感 → 必要なら「自分は保険ネタ置いてる」程度。

```
それめっちゃわかります…話題ストック切れた瞬間の顔固まるの、あるあるです
```

```
コメント待ちの10秒、体感1分ですよね。つなぎの二択、1個ポケットに入れておくと楽になります
```

```
「えー」が増える日、あります。保険ネタあるだけで呼吸変わるの、ほんとそう
```

アプリ誘導は **相手が悩みを深く書いてきたときだけ**、リプの末尾に一言。普段はしない。

## 5. プロフィールまわり

### 固定ポスト案（1本にまとめる）

```
雑談配信の「次の一文」をすぐ出せるネタカードアプリです。

こんな人向け
・沈黙が怖い
・話題用意してもすぐ枯れる
・コメント待ちの手が震える

▶ 使い方デモ（短い動画）
▶ 今日使えるお題はタイムラインへ

DL / Web: （URL）
```

### バイオ案

```
雑談配信の沈黙対策｜すぐ使えるネタカード
VTuber / Vライバー向け
お題を出して、次の一文を守る
↓ Web
```

### メディア方針

- 紹介動画を **3本ストック**（使い方 / お題めくり / 配信想定の手元）
- あるあるはテキスト主、週1で1枚イラストや簡易図解でも可（毎回同じ枠線カードは避ける）

| 曜日 | 夜の投稿 | 昼〜夕方の行動 |
|------|----------|----------------|
| 月 | A 時事ネタカード | 「沈黙」「話題切れ」検索でリプ3件 |
| 火 | A 時事ネタカード | 同上 |
| 水 | C デモ短尺 | 同上 |
| 木 | A 時事ネタカード | 同上 |
| 金 | A or D 沈黙Tips（どちらか1） | 同上 |
| 土 | B 人間味（ネタがある日だけ） | リプ多め |
| 日 | 休み or A1本のみ | いいね中心で可 |

- **本投稿は1日0〜1本**（連投しない）
- **リプ活動は毎日3〜5件**（これが伸びの本体）
- **A（時事ネタカード）を週の過半数に**。沈黙対策同文はゼロ

## 7. 初速の作り方（投稿直後）

フォロワー28人では、投稿後 **最初の10〜20 IMP** が生死。

1. 投稿直後に **自分でスレッド返信**（補足・お題の掘り方・二択）
2. 知り合い・別垢があれば、最初の数分でいいね／一言リプを頼む（不自然な量はNG）
3. 投稿後15分は通知を見て、来たリプにすぐ返す
4. 「いいね待ち」だけで放置しない

## 8. KPI（初期アカウント用）

週次で見る。フォロワー数より先にこれら。

| 指標 | 今の目安 | 4週後の目安 |
|------|----------|-------------|
| 通常投稿のIMP | 5〜100 | 中央値 80〜300 |
| いいね/投稿 | ほぼ0 | 平均 2〜5 |
| リプ/投稿 | ほぼ0 | 平均 1〜3 |
| プロフアクセス | 少 | 週で増加傾向 |
| 外部からのリプ経由フォロー | ほぼ0 | 週に数件 |

「バイラル1本」は狙わない。**反応が付く投稿の比率**を上げる。

## 10. やらないこと（再掲）

- 毎日同じ型の宣伝
- ハッシュタグ大量付け
- 知らない配信者への「アプリどうぞ」DM / リプ営業
- 数字自慢・虚偽の社会的証明
- 反応がないのに投稿頻度だけ上げる

### GitHub Secrets（要登録）

- `API_KEY_HANATANE`
- `API_SECRET_KEY_HANATANE`
- `ACCESS_TOKEN_HANATANE`
- `ACCESS_TOKEN_SECRET_HANATANE`
- （任意）`BEARER_TOKEN_HANATANE`

### 旧「沈黙対策 #n」自動投稿について

ハナタネアプリ側（`source: …hanatane_ap`）の同文連投は **別系統** の可能性がある。  
本 bot 導入後は、アプリ内の X 自動投稿を停止し、重複を避けること。
