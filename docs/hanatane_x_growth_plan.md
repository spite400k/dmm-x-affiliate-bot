# @hanatane_app X投稿 改善案

Grok診断（フォロワー28・IMP 5〜100・同文連投・エンゲージほぼゼロ）を踏まえた、**今すぐ実行できる**改善プラン。

現状フェーズは「拡散」ではなく **認知の種まき**。ゴールは「おすすめに載る」ではなく、**VTuber・雑談配信者のタイムラインに顔を出すこと**。

---

## 1. 診断の要約（優先度順）

| 優先度 | 問題 | 影響 |
|--------|------|------|
| P0 | 【沈黙対策 #n】同文連投 | スパム寄り判定・新鮮味ゼロ |
| P0 | 初速エンゲージがほぼゼロ | おすすめ配信に乗らない |
| P1 | コミュニティ接点が薄い | 外部流入ゼロ |
| P1 | 投稿フォーマットが固定 | スクロールでスキップされる |
| P2 | 固定ポスト・デモ動画が弱い | プロフ来訪者が離脱 |

**やめること（即日）**

- 同じ「沈黙対策」定型文の連番連投
- 「ネタカード画像＋同じ説明文」だけの日課
- ハッシュタグの羅列だけ／反応ゼロの独り言投稿

**やること（今週から）**

- 投稿パターンを最低5種に分散
- 配信者投稿へのリプを「投稿」より優先
- 投稿直後にスレッド自己返信で初速を付ける

---

## 2. 運用の基本方針（フォロワー〜100人まで）

1. **売り込み比率を下げる**  
   1日の目安：価値提供 60% / 共感・あるある 25% / アプリ訴求 15%
2. **「使える」投稿を増やす**  
   配信中にコピペできるお題・質問・つなぎトークをそのまま出す
3. **反応が取りやすい形にする**  
   二択・質問・「あるある番号をリプして」など、リプのハードルを下げる
4. **時間帯**  
   目安は **21:00〜24:00**（雑談枠が動きやすい帯）。昼はリプ活動、夜は本投稿
5. **ハッシュタグ**  
   1投稿あたり **0〜2個**（`#雑談配信` `#VTuber` `#Vライバー` から状況で1つ）。毎回全部付けない

---

## 3. 投稿パターン（5本柱）

同じ柱を連続させない。ローテーション例は §6。

### A. 即使用ネタ（コピーして配信で使える）

狙い: 保存・リポストされやすい。アプリ名は末尾かスレッド2に回す。

### B. 沈黙あるある（共感→保存）

狙い: 「わかる」いいね／リプ。売り込みはしないか、軽い一言だけ。

### C. 画面デモ（15〜30秒）

狙い: 「何のアプリか」を一目で伝える。週2本までで十分。

### D. 開発メモ / 小さな改善

狙い: 人柄と継続性。フォロー理由になる。

### E. コミュニティ参加（投稿ではなく行動）

狙い: 認知の主戦場。投稿枠とは別に **毎日やる**。

## 4. すぐ使える投稿文案

### A. 即使用ネタ

**A-1（二択）**
```
雑談で沈黙したら、まずこれ投げてみて👇

「きのこの山派？ たけのこの里派？」

答えが来たら「なんでそっち？」で3分は持つ。

#雑談配信
```

**A-2（つなぎトーク）**
```
コメントが止まったときの「つなぎ」3つ

1. 今日の晩ごはん何だった？
2. 今週いちばん疲れた瞬間は？
3. 最近「買ってよかった」ものある？

短く聞いて、10秒待つ。それだけで空気が戻ることが多い。
```

**A-3（お題カード風・アプリ導線弱め）**
```
今日の雑談お題（そのまま読んでもOK）

「子どものころ、親にバレたくなかったこと」

掘り方ヒント:
・バレそうになった瞬間
・今思うと全然大したことない話
・リスナーにも振る（「みんなのは？」）
```

**A-4（スレッド型：1投稿目）**
```
雑談60分を「ネタ3本」で組む型

① 自分の話（10分）
② 二択／ランキング（15分）
③ リスナー質問（残り）

台本じゃなくて「見出し」だけでいい。
続き↓
```
（2投稿目で具体例、3投稿目で「お題が欲しいときはプロフのアプリ」）

### B. 沈黙あるある

**B-1**
```
雑談あるある

・話題用意したのに、開始3分で全部使い切る
・コメント待ってる間がいちばん長い
・「えー」が口癖になる日

わかる人、番号でリプしてほしい。
```

**B-2**
```
沈黙が怖いんじゃなくて、
「沈黙のあとに何も出てこない自分」が怖い。

だから保険ネタをポケットに入れておく。
紙でもアプリでもいい。あるだけで呼吸が変わる。
```

**B-3（軽い導線）**
```
配信中に話題が切れたら、
スマホを見下ろす時間が一番バレる。

だから「次のお題」はワンタップで出せる形がいい。
（自作メモでも、カードアプリでも）
```

### C. 画面デモ用キャプション

**C-1**
```
雑談で詰まったとき用。
お題をサッと出すだけの短いデモ（20秒）

「何話すか」より「次の一文がある」安心感。
```

**C-2**
```
ネタカードを「読む」んじゃなくて「振る」。

配信者「これどう思う？」
→ コメントの入口になる。

使い方デモ↓
```

### D. 開発・改善報告

**D-1**
```
今日の改善メモ

・お題の出方が「同じ雰囲気」に寄らないよう調整中
・「沈黙対策」用途のラベルを見直し

小さく直して、配信者の手元で使いやすくする。
```

**D-2（ユーザーの声がある場合）**
```
届いた声（許可いただいて紹介）

「お題があるだけで、コメント待ちの手が震えなくなった」

こういう一文が一番うれしい。ありがとう。
```

### E. リプ用テンプレ（他アカウントへ）

売り込み禁止。まず共感 → 必要なら「自分は保険ネタ置いてる」程度。

```
それめっちゃわかります…話題ストック切れた瞬間の顔固まるの、あるあるです
```

```
コメント待ちの10秒、体感1分ですよね。つなぎの二択、1個ポケットに入れておくと楽になります
```

```
「えー」が増える日、あります。保険ネタあるだけで呼吸変わるの、ほんとそう
```

アプリ誘導は **相手が悩みを深く書いてきたときだけ**、リプの末尾に一言。普段はしない。

## 5. プロフィールまわり

### 固定ポスト案（1本にまとめる）

```
雑談配信の「次の一文」をすぐ出せるネタカードアプリです。

こんな人向け
・沈黙が怖い
・話題用意してもすぐ枯れる
・コメント待ちの手が震える

▶ 使い方デモ（短い動画）
▶ 今日使えるお題はタイムラインへ

DL / Web: （URL）
```

### バイオ案

```
雑談配信の沈黙対策｜すぐ使えるネタカード
VTuber / Vライバー向け
お題を出して、次の一文を守る
↓ Web
```

### メディア方針

- 紹介動画を **3本ストック**（使い方 / お題めくり / 配信想定の手元）
- あるあるはテキスト主、週1で1枚イラストや簡易図解でも可（毎回同じ枠線カードは避ける）

## 6. 週間スケジュール例（軽量）

| 曜日 | 夜の投稿 | 昼〜夕方の行動 |
|------|----------|----------------|
| 月 | A 即使用ネタ | 「沈黙」「話題切れ」検索でリプ3件 |
| 火 | B あるある | 同上 |
| 水 | C デモ短尺 | 同上 |
| 木 | A 別切り口 | 同上 |
| 金 | D 改善メモ or 声 | 同上 |
| 土 | B or 質問投稿 | リプ多め |
| 日 | 休み or A1本のみ | いいね中心で可 |

- **本投稿は1日0〜1本**（連投しない）
- **リプ活動は毎日3〜5件**（これが伸びの本体）
- 沈黙対策シリーズを続けるなら **週1まで**、毎回エピソードを変える（連番ハッシュは不要）

---

## 7. 初速の作り方（投稿直後）

フォロワー28人では、投稿後 **最初の10〜20 IMP** が生死。

1. 投稿直後に **自分でスレッド返信**（補足・お題の掘り方・二択）
2. 知り合い・別垢があれば、最初の数分でいいね／一言リプを頼む（不自然な量はNG）
3. 投稿後15分は通知を見て、来たリプにすぐ返す
4. 「いいね待ち」だけで放置しない

---

## 8. KPI（初期アカウント用）

週次で見る。フォロワー数より先にこれら。

| 指標 | 今の目安 | 4週後の目安 |
|------|----------|-------------|
| 通常投稿のIMP | 5〜100 | 中央値 80〜300 |
| いいね/投稿 | ほぼ0 | 平均 2〜5 |
| リプ/投稿 | ほぼ0 | 平均 1〜3 |
| プロフアクセス | 少 | 週で増加傾向 |
| 外部からのリプ経由フォロー | ほぼ0 | 週に数件 |

「バイラル1本」は狙わない。**反応が付く投稿の比率**を上げる。

## 10. やらないこと（再掲）

- 毎日同じ型の宣伝
- ハッシュタグ大量付け
- 知らない配信者への「アプリどうぞ」DM / リプ営業
- 数字自慢・虚偽の社会的証明
- 反応がないのに投稿頻度だけ上げる
